# Resolve bc_list_name keys/indices to file paths

Resolve bc_list_name keys/indices to file paths

## Usage

``` r
.resolve_bc_lists(x, barcodes_files)
```

## Arguments

- x:

  list of FlexiplexSegment objects or list of FlexiplexGroup objects

- barcodes_files:

  named or unnamed (only allowd when length is 1) character vector of
  barcode file paths
