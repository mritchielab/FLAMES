# scMixology short-read gene counts - sample 2

Short-read gene counts from long and short-read single cell RNA-seq
profiling of human lung adenocarcinoma cell lines using 10X version 2
chemstry. See Tian, L. et al. Comprehensive characterization of
single-cell full-length isoforms in human and mouse with long-read
sequencing. Genome Biology 22, 310 (2021).

## Usage

``` r
scmixology_lib10
```

## Format

\## \`scmixology_lib10\` A `SingleCellExperiment` with 7,240 rows and 60
columns:

## Source

\<https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE154869\>

## Value

A `SingleCellExperiment` object
